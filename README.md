# Perfil de Andrés Camacho

Portafolio personal profesional que muestra información sobre formación académica, experiencia profesional, certificaciones, títulos y proyectos desarrollados.

## Descripción

Este proyecto es un sitio web personal que presenta el perfil profesional de Andrés Camacho Sánchez, Desarrollador de Software Junior e Ingeniero en Sistemas en formación. El sitio incluye información detallada sobre su experiencia práctica en desarrollo de aplicaciones web y de escritorio, integración de bases de datos, participación en proyectos reales y freelance, así como una galería completa de proyectos profesionales.

## Perfil Profesional

Desarrollador de Software Junior e Ingeniero en Sistemas en formación, con experiencia práctica en desarrollo de aplicaciones web y de escritorio, integración de bases de datos y participación en proyectos reales y freelance. Con sólidos conocimientos en programación orientada a objetos, desarrollo full stack, bases de datos relacionales y NoSQL, y metodologías ágiles (Scrum). Orientado a la creación de soluciones eficientes, seguras y escalables, con capacidad para trabajar en equipo, aprender rápidamente nuevas tecnologías y aportar valor en entornos de desarrollo junior.

## Estructura del Proyecto

El sitio web incluye las siguientes secciones:

- **Inicio**: Página principal con información de presentación y resumen profesional
- **Sobre Mi**: Información personal detallada, experiencia profesional, habilidades técnicas e idiomas
- **Contactos**: Información de contacto y redes sociales
- **Certificados**: Títulos y certificaciones obtenidas
- **Proyectos**: Galería de proyectos profesionales con descripciones, tecnologías utilizadas y enlaces a sitios web

## Proyectos Incluidos

El apartado de Proyectos incluye los siguientes proyectos profesionales:

1. **Observatorio de Datos Públicos CR**: Plataforma independiente dedicada al monitoreo técnico y la visualización de datos gubernamentales de Costa Rica
2. **Dashboard de Ventas Anuales**: Dashboard web estático para visualización de datos mensuales con gráficos interactivos
3. **Centro Integral Santo Domingo**: Sistema integral de gestión clínica y administrativa desarrollado con .NET Framework
4. **Portafolio Personal**: Sitio web personal profesional
5. **Escuela Félix Arcadio Montero Monge**: Plataforma web para comunicación escolar, avisos y recursos educativos
6. **Landing Page SPORTMAX**: Landing page moderna y atractiva desarrollada para SPORTMAX
7. **Dashboard de Análisis Financiero**: Dashboard diseñado para visualizar indicadores clave y analizar movimientos económicos
8. **Proyecto Asociación Desamparados Inclusivo**: Portal informativo para programas sociales y proyectos comunitarios

Cada proyecto incluye:
- Video demostrativo
- Descripción detallada
- Tags de categorización
- Tecnologías utilizadas (expandible)
- Enlaces a sitios web o credenciales de acceso público (cuando aplique)

## Características Técnicas

- Diseño responsive que se adapta a diferentes tamaños de pantalla
- Navegación lateral fija con menú desplegable
- Cards de proyectos con funcionalidad de expandir/colapsar para mostrar detalles
- Integración de videos para demostraciones de proyectos
- Sistema de tags para categorización de proyectos
- Botón de scroll to top para mejor navegación
- Favicon personalizado con diseño de letra "A" sobre fondo azul
