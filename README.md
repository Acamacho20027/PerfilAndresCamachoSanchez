# Perfil de Andrés Camacho

Portafolio personal que muestra información profesional, certificados, títulos y proyectos.

## Descripción

Este proyecto es un sitio web personal que presenta el perfil profesional de Andrés Camacho Sánchez, incluyendo información sobre su formación académica, certificaciones y experiencia.

## Diseñado por

**Andrés Camacho Sánchez**

## Estructura del Proyecto

El sitio web incluye las siguientes secciones:

- **Inicio**: Página principal con información de presentación
- **Sobre mi**: Información personal y profesional
- **Contactos**: Información de contacto y redes sociales
- **Certificados**: Títulos y certificaciones obtenidas

## Próximas Funcionalidades

Se tiene planeado agregar una nueva pestaña o apartado de **Proyectos** para mostrar proyectos profesionales en el futuro.

## Tecnologías Utilizadas

- HTML5
- CSS3
- Bootstrap
- Font Awesome (iconos)

## Archivos Principales

- `index.html` - Página de inicio
- `about.html` - Página sobre mi
- `contact.html` - Página de contactos
- `Titulos.html` - Página de títulos y certificados
